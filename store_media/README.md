# Store media — حروف (Huruf)

Captured from the real app (Flutter web build, release mode) at Google Play phone size:
**1080 × 1920 px (9:16), PNG**. Videos are **1080 × 1920, H.264 MP4, 30 fps**.

Game state used for the captures was seeded to look like a real mid-game profile
(player "سارة", level 133 / level 371, coins, streak, unlocked achievements).
